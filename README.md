# Technicolor
Transition from a 1940s noir detective-style alleyway to a colorful, pulp sci-fi-inspired futuristic metropolis.

## What It Is
A Unity VR game exploring thematic transitions and sleek camera movements.

## Tech
Unity | C#

## Context
Created as part of a VXR class, focusing on a pulp sci-fi aesthetic and immersive VR environments.
